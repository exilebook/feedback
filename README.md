# Exilebook feedback

Bug reports and ideas for [Exilebook](https://exilebook.online), a Path of Exile cheatsheet: item bases, crafting, map regex, Timeless and Cluster jewels, scarabs and poe.ninja prices.

The site's code is not in this repository. It exists for issues only.

## Report a bug or suggest an idea

[Open an issue](https://github.com/exilebook/feedback/issues/new). For a bug, please include:

- A link to the page
- What you expected and what you saw
- The league or patch, if it is about prices or mods

Issues are public, so please don't post anything private. To write privately, use the email on the [contact page](https://exilebook.online/contact).

Exilebook isn't affiliated with or endorsed by Grinding Gear Games. For questions about your account, purchases or the game itself, contact the game's support.

## По-русски

Здесь принимаем сообщения об ошибках и идеи для [Exilebook](https://exilebook.ru), шпаргалки по Path of Exile. Кода сайта в этом репозитории нет.

[Создайте issue](https://github.com/exilebook/feedback/issues/new). Если это ошибка, укажите:

- Ссылку на страницу
- Что ожидали увидеть и что увидели
- Лигу или патч, если дело в ценах или модах

Issue видны всем, поэтому не пишите в них ничего личного. Для личных вопросов есть почта на [странице контактов](https://exilebook.ru/contact).

Exilebook не связан с Grinding Gear Games. С вопросами об аккаунте, покупках и самой игре обращайтесь в поддержку игры.
